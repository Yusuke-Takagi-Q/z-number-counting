# A power saving in the count of generalized Z-numbers

**Yusuke Takagi** · Preprint · 2026

[Read the paper (PDF)](paper.pdf) · [Cite or download the archived version from Zenodo](https://doi.org/10.5281/zenodo.24538356)

## Abstract

Let P and Q be coprime integers with 2 ≤ Q < P < Q², and put β = P/Q. We give a power-saving upper bound for the number of positive real numbers ξ in an arbitrary interval of length X ≥ 2 such that the fractional part of ξβᵗ is less than 1/Q for every nonnegative integer t. Both the saving below $\log_Q\beta$ and the implied constant are computable from P and Q. For β = 3/2, we give the explicit bound $1.12\cdot10^{29}X^{\log_2(3/2)-2.222\cdot10^{-5}}$. A separate argument gives the larger saving 0.01059 with an ineffective implied constant. The same bounds apply to integer seeds with admissible correction words of a suitable finite length. The effective proof combines a determinant argument for adjacent blocks with Fourier cancellation for greedy words. The explicit bound at 3/2 uses a certified moment bound for products of twisted renewal operators over twelve digits.
